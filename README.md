# StationeryBox - Offline Personal Stationery Organizer

## About the project
  StationeryBox is an offline personal stationery organizer application developed using React Native.

## Description
  StationeryBox is an offline mobile application designed to help users organize & manage their personal stationary items. Users can add stationery items, update items details, delete items, search for items, filter items by category & view detailed information. All information is stored locally on the device.

## Main objectives
  To provide a simple & convenient way to organize & manage personal stationary items without requiring an internet connection.
